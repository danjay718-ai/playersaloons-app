# Managing Game Categories, Games & Tournaments (Admin Guide)

## Game Categories
- Manage categories under **CMS → Game Categories** (initial categories: **Video Games** and **Card & Board Games**).
- Admins can create, rename, reorder, activate, or deactivate categories.
- **Deactivating a category** hides its games and tournaments from player discovery and blocks new registrations, while allowing already-active matches, brackets, and payouts to finish cleanly.
- Categories cannot be deleted while any game (including archived games) still references them.

## Games & PlayStrategy Catalog
- Manage games under **CMS → Games**. Every game must belong to an active Game Category.
- For PlayStrategy titles (**Chess**, **International Draughts**, **Backgammon**, **Othello**), use the **PlayStrategy Quick-Fill** presets to configure the gameplay provider and rules cleanly.

## Tournaments & Head-to-Head Management
- Open **Tournaments** to create and manage recurring V2 tournament templates/occurrences or one-time competitions (daily, weekly, monthly, entry fees, prize pools, max teams, auto-cancel thresholds).
- Open **Head-to-Head** to monitor and manage 1v1 competitions.
- If a scheduled tournament fails to meet minimum participants by start time, the platform automatically cancels it and refunds all registered players.
